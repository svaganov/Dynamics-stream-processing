Цепочка обработки
Цепочка воркера Liquidsoap: источник AAC / HE-AAC / MP3 → EQ (10 полос) → усиление → компрессор → loudnorm → лимитер → выходы (AAC FDK / MP3 → свои точки Icecast). EQ, усиление, компрессор и лимитер подстраиваются живьём на работающем воркере; включение/выключение всех секций (включая loudnorm) — тоже живьём, параметры loudnorm и состав выходов — при перезапуске. Реестр станций хранится в streams.json рядом с app.py.
